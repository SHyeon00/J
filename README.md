# 1. 앱 이름과 한 줄 소개

**잠드림**은 수면 모드를 체험하고, 편안한 밤을 위한 실천을 관리하는 앱입니다.

## 2. 누구를 위한 앱인가

불면증이나 불규칙한 수면 때문에 불편함을 겪는 사람을 위한 앱입니다.

## 3. 할 수 있는 일

- 실천할 행동을 추가하고, 완료 표시를 켜거나 끄고, 삭제할 수 있습니다.
- 빈 제목이나 공백만 입력하면 추가되지 않고 안내가 나옵니다.
- 실천 목록과 완료 상태를 저장하고 다시 불러옵니다.
- 수면 모드를 시작하면 어두운 화면에 시작 시각과 기록 시간이 나옵니다.
- 종료하면 시작·종료 시각, 기록 시간, 데모 점수와 행동 제안을 볼 수 있습니다. 새로고침 전까지 최근 결과를 다시 열 수 있습니다.

수면 점수, 호흡 분석, 주간 그래프는 예시입니다. 실제 녹음이나 호흡 분석은 하지 않습니다.

## 4. 사용 방법

1. `오늘의 실천`에서 `예시 내일 할 일 정리하기`를 입력하고 `＋ 추가`를 누릅니다.
2. 항목 왼쪽 버튼을 눌러 완료 표시를 합니다. 다시 누르면 해제됩니다.
3. 지울 항목의 `삭제` 버튼을 누릅니다. 해당 항목만 사라집니다.

수면 모드는 아래의 `수면 시작`을 누른 뒤 `수면 종료`를 누르면 결과를 볼 수 있습니다.

## 5. 실행 방법

작업 폴더의 `index.html`을 브라우저로 엽니다. 설치나 서버 실행은 필요 없습니다.

터미널에서는 Windows는 `start index.html`, macOS는 `open index.html`을 사용합니다. 수정 후에는 Windows `F5`, macOS `Cmd+R`로 새로고침합니다.

## 6. 확인 방법

[회귀 점검표](docs/checklist.md)를 따라 확인하고, 사람이 결과 칸을 채웁니다.

- 콘솔에 빨간 오류가 없는지 확인합니다.
- 추가, 완료 표시와 해제, 가운데 항목 삭제, 빈 목록 안내를 확인합니다.
- 빈 제목과 공백은 막히고 정상 제목은 추가되는지 확인합니다.
- 새로고침과 탭 재열기 후 목록·순서·완료·삭제 상태가 유지되는지 확인합니다.

수면 모드 시작·종료와 결과 화면은 [AGENTS.md](AGENTS.md)의 확인 절차도 따릅니다.

## 7. 데이터 저장 안내

실천 목록은 브라우저의 `localStorage`에 저장됩니다. 다른 브라우저나 다른 주소에서는 보이지 않습니다. 브라우저 데이터를 지우면 목록도 사라질 수 있습니다.

저장이 실패하면 화면에 안내가 나옵니다. 수면 기록은 저장되지 않아 새로고침하면 초기화됩니다. 개인정보 대신 가상 데이터만 입력하세요.

## 8. 만든 과정

- **하네스 엔지니어링:** `AGENTS.md`에 작업 규칙을 두고, `docs/checklist.md`로 확인 방법을 정했습니다.
- **루프 엔지니어링:** 실패한 기준과 실제 결과를 피드백하고 해당 부분을 수정하도록 요청했습니다. 현재 `loop-log.md`가 없어 회차별 결과는 확인할 수 없습니다.
