## 회귀 점검표

개인 기록이 없는 테스트용 브라우저 환경에서 `index.html`을 열고, `오늘의 실천` 영역으로 이동한다. 기존 가상 실천 항목을 모두 삭제한 뒤 표를 위에서 아래 순서대로 확인한다. 저장 점검은 같은 브라우저의 일반 창에서 같은 파일 경로 또는 주소를 사용한다. 새로고침은 Windows `F5`, macOS `Cmd+R`을 누른다.

| 번호 | 항목 | 이렇게 확인한다 | 통과 조건 | 결과 |
|---|---|---|---|---|
| 점검 | 콘솔 오류 없음 | 개발자 도구(Windows `F12` / macOS `Cmd+Option+I`)의 콘솔 탭을 열고 필터를 비운다. 아래 항목을 모두 수행한 뒤 새로고침·탭 재열기 때도 콘솔을 확인한다. | 앱 로딩과 각 동작에서 빨간 오류 메시지가 나타나지 않는다. | |
| ① | 추가 | 입력칸에 `예시 하루 돌아보기`를 입력하고 `＋ 추가`를 한 번 누른다. | 해당 제목의 항목이 목록에 하나 나타나고 입력칸이 비워진다. | |
| ② | 완료 표시(다시 누르면 해제) | `예시 하루 돌아보기` 왼쪽의 완료 표시 버튼을 누르고, 표시가 바뀐 것을 확인한 뒤 같은 버튼을 다시 누른다. | 첫 클릭에는 체크 표시와 제목의 취소선이 나타난다. 두 번째 클릭에는 둘 다 사라지고 미완료 상태로 돌아온다. | |
| ③ | 가운데 일정 삭제 | `예시 내일 목표 적기`, `예시 방 정리하기`를 순서대로 추가한다. 세 항목 중 가운데인 `예시 내일 목표 적기`의 삭제 버튼만 누른다. | 가운데 항목만 사라지고 `예시 하루 돌아보기`, `예시 방 정리하기`가 그 순서로 남는다. | |
| 안내 | 빈 목록 안내 | 남은 두 항목을 각각 삭제해 목록을 완전히 비운다. | 항목이 없고 `오늘의 작은 목표를 하나 적어 보세요.`라는 안내가 나타난다. | |
| ④-1 | 빈 제목 | 입력칸을 완전히 비운 상태에서 `＋ 추가`를 누른다. | 항목이 추가되지 않고 입력칸 근처에 실천할 행동을 입력하라는 한국어 안내가 나타난다. 경고창은 뜨지 않는다. | |
| ④-2 | 공백만 입력 | 입력칸을 비운 다음 스페이스바를 세 번 누르고 `＋ 추가`를 누른다. | 공백 항목이 추가되지 않고 입력칸 근처의 한국어 안내가 보인다. | |
| ④-3 | 정상 제목 | 공백을 지우고 `예시 하루 돌아보기`를 입력한 뒤 `＋ 추가`를 누른다. | 제목이 목록에 하나 나타나고 입력 오류 안내가 사라진다. 입력칸도 비워진다. | |
| ⑤-1 | 추가 유지 | 방금 추가한 가상 항목을 삭제한다. `예시 하루 돌아보기`, `예시 내일 목표 적기`, `예시 방 정리하기`를 순서대로 추가한 뒤 새로고침하고 `오늘의 실천` 영역을 확인한다. | 세 항목이 중복 없이 같은 제목과 순서로 남아 있다. | |
| ⑤-2 | 완료·삭제 유지 | 첫 항목 `예시 하루 돌아보기`를 완료 표시하고, 가운데 항목 `예시 내일 목표 적기`를 삭제한다. 새로고침한 뒤 목록을 확인한다. | 첫 항목의 체크 표시와 취소선이 유지된다. 삭제한 가운데 항목은 다시 나타나지 않고, 첫 번째와 세 번째 항목만 같은 순서로 남는다. | |
| ⑤-3 | 창 다시 열기 | 앱 탭을 닫는다. 같은 브라우저의 일반 창에서 동일한 `index.html` 파일 경로 또는 주소를 다시 열고 `오늘의 실천` 영역을 확인한다. | ⑤-2의 두 항목과 순서가 유지되고 첫 항목은 완료 상태다. 삭제한 항목은 나타나지 않는다. | |
