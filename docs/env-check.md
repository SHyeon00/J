# 환경 확인 체크리스트

- [ ] VS Code에서 작업 폴더(Windows `C:\work\study-planner` / macOS `~/work/study-planner`)를 열었다 — 확인 방법: VS Code 탐색기와 터미널의 현재 경로가 해당 작업 폴더인지 확인한다.
- [ ] Codex 확장에 실습 계정으로 로그인했다 — 확인 방법: Codex 확장의 계정 메뉴에서 로그인 상태와 실습 계정을 확인한다.
- [ ] 작업 폴더 맨 위에 `AGENTS.md`가 있다 — 확인 방법: VS Code 탐색기에서 작업 폴더 바로 아래에 `AGENTS.md`가 있는지 확인한다.
- [ ] 새 대화에서 Codex가 `AGENTS.md` 규칙을 요약했다 — 확인 방법: 새 대화에서 프로젝트 규칙 요약을 요청하고 답변을 `AGENTS.md` 내용과 비교한다.
- [ ] 규칙에 어긋나는 요청(라이브러리 설치)을 Codex가 거절하거나 되물었다 — 확인 방법: 불필요한 라이브러리 설치를 요청하고 실제 설치 없이 규칙 위반을 설명하거나 확인을 요청하는지 확인한다.
- [ ] Codex가 파일을 만들거나 명령을 실행하기 전에 허락을 묻는다 — 확인 방법: 파일 생성 또는 명령 실행이 필요한 요청을 보내고 실행 전에 허락을 묻는지 확인한다.
- [ ] `docs/plan.md`와 `docs/prompt-design.md`가 있다 — 확인 방법: VS Code 탐색기의 `docs` 폴더에서 두 파일이 모두 있는지 확인한다.
- [ ] `git --version`이 동작한다 — 확인 방법: 터미널에서 `git --version`을 실행하고 Git 버전이 출력되는지 확인한다.
- [ ] 브라우저(Windows: Chrome 또는 Edge / macOS: Chrome 또는 Safari)가 열린다 — 확인 방법: 운영체제에 맞는 브라우저를 실행하고 창이 열리는지 확인한다.
- [ ] 코드와 문서에 개인정보 · 비밀번호 · API 키가 없다 — 확인 방법: 코드와 문서 전체를 검색·검토해 개인정보, 실제 비밀번호, API 키가 포함되어 있지 않은지 확인한다.
