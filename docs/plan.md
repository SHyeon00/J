# 앱 기획서

## 1. 앱 이름
잠드림
## 2. 사용자 (누가 쓰나)
불면증, 수면 불균형 등 수면에서 불편함을 겪는 사람들
## 3. 해결할 문제 (왜 필요한가)
불면증, 수면 불균형, 등등의 수면에 관련한 불편함을 해결
## 4. 기능 목록 (꼭 필요한 기능 / 있으면 좋은 기능)
수면모드(음성이 켜지고 수면중 호흡 분석), 수면모드 종료 후 분석된 정보, 솔루션 제공
## 5. 화면 구성 (위에서 아래 순서)
탭바 - 최근 수면 보드 - 최근 7일 수면 분석 표 - 수면 시작하기(플로팅 버튼)
## 6. 사용 흐름 (사용자가 하는 행동 순서)
수면모드 활성 및 음성 수집 동의 - 수면모드 종료 후 분석된 결과 보기 - 솔루션 보기
## 7. 만들지 않을 것
쓸모없는 파일
## 8. 완료 기준
메인 mvp 기능 완성
